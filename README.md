# Particle Studio

**Превратите логотип в живую анимацию из частиц — и вставьте её на любой сайт в один клик.**

Загружаете картинку → она собирается из частиц и реагирует на курсор → экспортируете готовый код → вставляете на сайт как прелоадер, логотип, 404-страницу или hero-фон.

---

## Возможности

- 🖼 **Любые изображения** — PNG с прозрачностью, JPG (фон обрезается по цвету автоматически), SVG (с `width`/`height`)
- 🖱 **Интерактивность** — частицы избегают курсора, клик создаёт ударную волну
- 🎛 **Гибкая настройка** — физика, резина, хаос, радиус, скорость, плотность, зерно, 5 видов сборки
- 🧩 **Пресеты** — «Песок», «Резина», «Дымка» одним кликом
- 📦 **3 формата экспорта** — standalone HTML, Embed с внешним файлом, Inline для конструкторов сайтов
- 🚀 **Без зависимостей** — чистый JS: WebGL с фолбэком на Canvas 2D
- 🛡 **Shadow DOM** — стили виджета не конфликтуют со стилями вашего сайта
- ⚡ **Производительность** — тиры качества, автоопределение слабых устройств, пауза вне экрана, адаптивное число частиц
- ♿ **Доступность** — уважает `prefers-reduced-motion` (статичная версия логотипа)

## Быстрый старт (конструктор)

```bash
git clone <url-вашего-репозитория>
cd particle-studio
npx serve   # или откройте index.html через Live Server в VS Code
```

> ⚠️ Не открывайте `index.html` двойным кликом — экспорту нужен локальный сервер, чтобы прочитать движок.

1. Перетащите картинку в окно.
2. Выберите пресет и настройте анимацию (шестерёнка — расширенные настройки).
3. Выберите режим: **Блок** или **Прелоадер**.
4. Выберите формат экспорта и нажмите **Копировать** / **Сохранить в HTML**.

## Форматы экспорта

| Формат | Что получаете | Когда выбирать |
|---|---|---|
| **HTML** | Самодостаточная `.html`-страница | Посмотреть, показать клиенту |
| **Embed** | Сниппет + отдельный `particle.js` | Свой сайт, можно загрузить файл (кешируется браузером) |
| **Inline** | Один блок кода, всё внутри | Tilda, WordPress, Wix — когда файлы загрузить нельзя |

## Сценарии использования

### Логотип в блоке

```html
<div id="my-logo" style="width:100%;height:400px;"></div>
<script src="/js/particle.js"></script>
<script>
  ParticleStudio.mount("#my-logo", {
    image: "/logo.png",
    effect: "rubber"
  });
</script>
```

Размер блока задаёт контейнер — можно сделать и на весь экран:
`style="position:fixed;inset:0;z-index:-1;"` (фон позади контента).

### Прелоадер на весь экран

```html
<script src="/js/particle.js"></script>
<script>
  var ps = ParticleStudio.fullscreen({ image: "/logo.png" });
  window.addEventListener("load", function () {
    setTimeout(function () { ps.hide(); }, 400);
  });
</script>
```

`ps.hide()` — частицы разлетаются, слой полностью демонтируется.
Страховка от «вечного» прелоадера: `fallbackHideTimeout: 7000`.

### Декларативная встройка (без кода)

```html
<script src="particle.js" data-ps-auto></script>
<div data-ps-image="/logo.png" data-ps-effect="sand" style="height:300px"></div>
```

### React

```jsx
useEffect(() => {
  const ps = ParticleStudio.mount(ref.current, {
    image: "/logo.png",
    pointerEvents: false // клики проходят сквозь анимацию
  });
  return () => ps.destroy();
}, []);
```

## API

### `ParticleStudio.mount(target, options)` → instance

| Опция | Тип / значения | По умолчанию | Описание |
|---|---|---|---|
| `image` | string (URL / dataURL) | — | Изображение |
| `effect` | `sand` \| `rubber` \| `haze` | — | Пресет |
| `physics` | 0..1 | 0.5 | Сила отталкивания курсором |
| `rubber` | 0..1 | 0.35 | Упругость и «тяга» за курсором |
| `chaos` | 0..1 | 0.25 | Случайное дрожание |
| `radius` | px | 50 | Радиус влияния курсора |
| `speed` | 0.3..2.5 | 1 | Общая скорость |
| `density` | 0..1 | 0.7 | Плотность частиц |
| `grain` | 0..1 | 1 | Размер частиц |
| `entry` | `random` \| `sides` \| `center` \| `ring` \| `rain` | `random` | Вид сборки |
| `logoSize` | 16..1024 | 512 | Макс. размер логотипа (вписывается в контейнер) |
| `background` | `auto` \| `transparent` \| CSS | `auto` | Фон |
| `pointerEvents` | bool | `true` | Реагировать на курсор |
| `interaction` | `cursor` \| `none` | `cursor` | Режим интерактива |
| `motion` | `auto` \| `full` \| `reduced` | `auto` | Reduced motion |
| `quality` | `auto` \| `high` \| `balanced` \| `lite` | `auto` | Качество рендера |
| `silent` | bool | `false` | Не выводить предупреждения |

Дополнительно для `fullscreen()`: `hideOnLoad`, `hideDelay`, `fallbackHideTimeout`, `applyPageTheme`, `applyPageBackground`, `zIndex`.

Хуки: `onReady`, `onError`, `onTheme`, `onBackground`.

### Методы инстанса

| Метод | Описание |
|---|---|
| `play()` / `pause()` | Запуск / пауза анимации |
| `show()` / `hide()` | Показать / скрыть (fade) |
| `scatterOut()` | Разлёт частиц с исчезновением |
| `setImage(src)` | Заменить изображение |
| `update(patch)` | Обновить любые опции на лету |
| `destroy()` | Полностью убрать инстанс (без утечек) |

### Коды ошибок (`onError`)

| Код | Причина |
|---|---|
| `target` | Контейнер не найден |
| `load` | Не удалось загрузить изображение |
| `svg-size` | SVG без `width`/`height` |
| `empty` | В маске нет видимых пикселей |
| `cors` | `getImageData` заблокирован (CORS) |

## Производительность

- **WebGL** рендерит до 150 000 живых частиц + статичный слой для больших логотипов; на слабых устройствах — автоматическое снижение tiers.
- **IntersectionObserver** — анимация ставится на паузу, когда блок вне экрана.
- **Адаптация** — число частиц подстраивается под реальное время кадра.
- **Фолбэк** — при отсутствии WebGL используется Canvas 2D.


## Памятка по картинкам

- PNG с прозрачностью — лучший вариант.
- JPG: фон обрежется по цвету автоматически.
- SVG — только с прописанными `width` и `height`.
- Держите файл до ~200–300 КБ: для Inline картинка вшивается в код.
